# Золотой бот (gold-bot)

Телеграм-бот торговли золотом: курс ЦБ РФ (доллар + золото 999) и Сбербанка в закрепе группы,
новости про драгметаллы и журнал сделок в Google Sheets.

## Что делает

- **Закреп в группе** (обновляется раз в день утром, `PIN_HOUR`):
  - доллар ЦБ РФ;
  - золото 999 ЦБ ₽/г + изменение за день (%);
  - Сбербанк 999: покупка / продажа (автоподтяжка с зеркала investzoloto);
  - Сбербанк 585: продажа (= Сбер 999 × 0.585).
- **Новости** про драгметаллы из RSS investing, несколько раз в день, с дедупом.
- **Журнал сделок** в Google Sheets по кнопкам «Купить»/«Продать»: вес + цена/г → сумма,
  средний курс покупки/продажи (взвешенный) в шапке.

## Источники данных (проверено с сервера)

| Данные | Источник |
| --- | --- |
| Доллар ЦБ | `cbr.ru/scripts/XML_daily.asp` (R01235) |
| Золото 999 ₽/г | `cbr.ru/scripts/xml_metall.asp` (Code=1, win-1251) |
| Сбербанк 999 | зеркало `investzoloto.ru/gold-sber-oms/` (Сбер напрямую с сервера недоступен) |
| Новости | `ru.investing.com/rss/news_11.rss` |

Автоподтяжка Сбера — с неофициального зеркала: при смене вёрстки может отвалиться,
тогда работает запасной ручной ввод (кнопка «🏦 Курс Сбера»).

## Файлы

| Файл | Назначение |
| --- | --- |
| `gold_bot.py` | Telegram-бот (aiogram v3): кнопки, FSM сделок, закреп, планировщики |
| `rates.py` | Курсы: ЦБ доллар/золото + Сбер с зеркала, сборка текста закрепа |
| `news.py` | RSS-новости: загрузка, фильтр по драгметаллам, дедуп |
| `journal.py` | Журнал сделок в Google Sheets (gspread) |
| `config.py` | Токены и настройки (в git не коммитится, см. `config.example.py`) |
| `deploy.sh` | Деплой на сервере: git pull → md5 → py_compile → restart |

## Установка на сервере

```
cd /root/gold-bot
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp config.example.py config.py    # заполнить токен, GROUP_CHAT_ID, JOURNAL_BOOK_ID
# положить google-key.json (ключ сервис-аккаунта)
chmod +x deploy.sh
```

Сервис systemd `gold-bot` запускает `venv/bin/python gold_bot.py`.

## Проверка модулей офлайн

```
python3 rates.py     # парсинг ЦБ + Сбер на реальных образцах
python3 news.py      # фильтр новостей
python3 journal.py   # расчёт средних
```
